# Aetheria: security and robustness audit

Scope: `index.html`, `server.js` and the 16 Aetheria modules in `src/` (engine, ui, vfx, audio, physics_juice, levels_bosses, ai_director, progression, weapons_relics, companions_ultimates, events_arena, missions_campaign, loot_synergy, talent_tree, elite_affixes, daily_trials).

Method: grep for risky patterns, a read of every hit in context, then two throwaway Playwright probes run against `server.js` on ports 8937 and 8938. The probe scripts were deleted afterwards. Their raw results are in `playtest-results/aetheria-security/probe-results.json` and `probe2-results.json`. `npm run playtest` was not run.

## Categories with nothing found

- **Injection:** none found. All 14 `innerHTML` sinks were reviewed (`ui.js` 785, 789, 975, 1065, 1145, 1264, 1487, 1517, 1887, 2120, 2146; `talent_tree.js` 958, 1057, 1109). Every dynamic value goes through `escapeHtml`, and colors go through `sanitizeColor`. `talent_tree.js` interpolates only static catalog fields (`t.icon`, `t.id`, the numeric `cost`) plus escaped text. A runtime check put `"<img src=x onerror=alert(1)>"` into `unlockedSkins` and `activeSkin`; the catalog whitelist in `progression.js:265-280` dropped it. The daily-trials and missions text is drawn with `ctx.fillText`, and notifications use `textContent`. There is no `eval`, `new Function`, `document.write` or string-argument timer.
- **Third-party scripts:** none. All `<script>` tags are local (`index.html:2534-2552`).
- **Secrets:** none found in client code. `.env`, `CLAUDE.local.md` and `.claude/settings.local.json` are git-ignored.
- **Main save (`aetheria_save_v1`, `progression.js:253-336`):** validated well. Verified: truncated JSON `{"gold":` falls back to defaults and the run starts. With wrong types (`"gold":"9e99"`, `"level":"x"`, `"damage":1e9`, `"speed":-5`), gold and level fall back to defaults, `damage` is clamped to 15 and `speed` to 0, and the run starts. Arena record and hunter XP use `parseInt(...) || 0`, which is safe.
- **Listeners, timers and restarts:** no leak. Verified with CDP `DOMDebugger.getEventListeners(window)`: 22 listeners before and 22 after 30 alternating New Game / Arena restarts. Init guards are in place: `GameRelics._hasBoundInput`, `GameCompanions.initialized`, `GameMissions._isInitialized`. The audio scheduler `setInterval` is cleared in `stopBGM()` before each restart. The notification `setTimeout` is cleared before it is re-armed. Canvas `save` depth returned to 0 after the restarts.
- **Arrays that grow during a run:** none found by code review. VFX arrays are capped (`MAX_PARTICLES`, `MAX_FLOATING_TEXTS`, `MAX_CRATERS` and so on, in `vfx.js:403`, `2583-2784`). Companion particles are capped at 200 (`companions_ultimates.js:985`). Elite, loot and shadow-trap arrays are spliced or reset per region. Dead enemies are spliced (`engine.js:1611`). Runtime samples stayed bounded (≤ 8 enemies, ≤ 227 VFX particles, 60 floating texts at the cap), with a heap of 5-8 MB. Limitation: both 60-90 s arena probes paused themselves after about 10-23 s of game time behind a relic-draft modal that the probe failed to close, so long-run growth rests mostly on code review.
- **NaN propagation:** none found. Every vector normalization is guarded (`dist > 0`, `|| 1`, `len > 0.0001`; `engine.js` 1427, 1586, 1625, 2210-2413, 2631; `ai_director.js` 996, 1030, 1069; `physics_juice.js` 269, 329; `companions_ultimates.js` 570, 646, 702; `events_arena.js` 618-626). Plugin multipliers are filtered with `isFinite` (`engine.js:1004-1007`), and the game-over stats are coerced to numbers. No NaN player or enemy positions appeared in any sample.
- **Unguarded optional modules:** none found. Engine calls into other modules are guarded with `window.X && typeof ... === 'function'`, and plugin hooks are wrapped in `try/catch` (`engine.js:953-991`).
