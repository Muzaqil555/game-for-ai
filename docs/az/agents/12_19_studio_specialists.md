# 12–19-cu Agentlər: Yaradıcı Studiya, Performans və Biznes Mütəxəssisləri

- **Təyin edilmiş Model:** `Gemini 3.8 Flash (High)` (`invoke_subagent` zamanı `Model: "flash"`)
- **Birbaşa Rəhbər:** 4-cü Agent — CEO (`Gemini 4 Argon High`)

---

## 1. Səs, Qrafika və Ssenari Qrupu (12–14)

### 12. `audio_designer` — Səs və Musiqi Mütəxəssisi
- Oyun və tətbiqlər üçün səs effektləri (SFX), fon musiqisi (BGM), Web Audio API prosedural sintezatorlar və ya ElevenLabs audio aktivləri yaradır.

### 13. `art_director` — Qrafika, Effekt və Animasiya Rəssamı
- 2D/3D vizual aktivlər (sprites, SVG, 3D modellər), shader-lər, partlayış/işıq effektləri (particles/bloom) və yüksək səviyyəli animasiyalar hazırlayır.

### 14. `game_writer` — Ssenarist və Oyun Balansı Dizayneri
- Oyunun hekayəsini, mərhələlərini (levels), düşmən/silah/iqtisadiyyat balansını, tapşırıqları (quests) və oyunçu motivasiyasını qurur.

---

## 2. Sürət, Təmir və Canlıya Çıxarma Qrupu (15–17)

### 15. `performance_optimizer` — FPS və Sürət Mühəndisi
- Gecikmələri (lag), yaddaş sızmalarını (memory leaks) və ağır kodları təmizləyir, oyunu/tətbiqi 60–120+ FPS sürətinə qaldırır.

### 16. `devops_deployer` — Canlıya Çıxarma (Deploy) Mütəxəssisi
- Layihəni paketləyir, lokal serverdə və ya buludda (Cloudflare, Vercel, GitHub) işə salır və birbaşa işlək link təqdim edir.

### 17. `bug_fixer` — Avtomatik Xəta Düzəldən (Debugger)
- 5 İstifadəçi (Tester) agentinin tapdığı xətaları və bəyənilməyən hissələri dərhal kodda təmir edir.

---

## 3. Kəşfiyyat və Biznes Qrupu (18–19)

### 18. `market_researcher` — Rəqib və İdeya Kəşfiyyatçısı
- İnternetdə ən uğurlu oxşar oyunları/proqramları araşdırır və layihəni fərqləndirəcək ən güclü özəllikləri tapır.

### 19. `monetization_expert` — Qazanc və Baza Artırma Mütəxəssisi
- Oyun içi mağaza, VIP/abunəlik, gündəlik bonuslar, liderlər lövhəsi və istifadəçi saxlama (retention) mexanikalarını qurur.
