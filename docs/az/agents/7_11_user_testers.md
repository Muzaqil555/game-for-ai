- **Birbaşa Rəhbər:** 4-cü Agent — CEO (`Gemini 4 Argon High`)

## İstifadəçi Profilləri və Vəzifələri
Hazırlanan hər bir proqramı və ya oyunu real olaraq işlədib öz baxış bucaqlarından **nəyi bəyəndiklərini (Pros)** və **nəyi bəyənmədiklərini (Cons)** CEO-ya bildirirlər:

1. **7-ci Agent (`user_casual`) — Adi / Gündəlik İstifadəçi:**
   Sadəlik, rahatlıq və ilk baxışdan anlaşılma dərəcəsini yoxlayır.
2. **8-ci Agent (`user_hardcore_gamer`) — Tələbkar Oyunçu / Power User:**
   FPS, sürət, oyun mexanikası, fizika, idarəetmə həssaslığı və əyləncə səviyyəsini yoxlayır.
3. **9-cu Agent (`user_ui_critic`) — Dizayn və Vizual Tənqidçi İstifadəçi:**
   Rənglər, şriftlər, animasiyalar, düymələrin rahatlığı və vizual keyfiyyəti qiymətləndirir.
4. **10-cu Agent (`user_impatient`) — Səbirsiz / Xəta Axtaran İstifadəçi:**
   Sürətlə klikləyərək, gözlənilməz hərəkətlər edərək donmaları, gecikmələri və bug-ları tapır.
5. **11-ci Agent (`user_explorer`) — Detalçı / Funksionallıq Axtaran İstifadəçi:**
   Bütün funksiyaları tək-tək yoxlayır, nəyin əla olduğunu və nəyin çatışmadığını deyir.
